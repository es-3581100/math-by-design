Human / agent split

HTML labs are for seeing, touching and inspecting the design space. Python is the reproducible palette/math engine for agents and build tooling. The inline compiler above remains intentionally lightweight and exploratory; it must not silently override the Python engine when exact generation or geometry provenance matters.

01 / grammar

Separate the decisions.

The system stays generative only if layout, material, color and interaction remain separable. Choosing one must not silently force the others.

8→1

Hierarchy / where

Phi Flow assigns authority and reading order: claim → context → proof → decision → metadata → exit.

□

Material / what

Oxide, Cryo, Paper, Signal and hero languages define surface character without replacing the layout contract.

τ φ ρ

Color / relation

Spiral families, convergence nodes and Rauzy samples create related color behavior rather than arbitrary swatch picking.

Interaction / handoff

Prompts, overlays and temporary emphasis route attention; semantic content remains the destination.

06 / handoff protocol
Each actor owns an output.

        
Do not silently revise a previous actor’s decision. Return a verifiable artifact or an explicit escalation.

      

      

        

          
ActorReceivesProducesStop / escalation

          
            
01 / PlannerAudience, purpose, evidence, desired actionSix-slot content plan, risks, scope, acceptance testsMissing evidence becomes an explicit placeholder.

            
02 / WriterApproved slot planClaim, context, proof, CTA, metadata, exitNo fake proof or silently strengthened claim.

            
03 / BuilderApproved content + canonical layout contract + selected material/color packetResponsive semantic HTML/CSS with tile rolesDo not fork layout authority to solve a styling problem.

            
04 / ReviewerBuilt artifact + planned rolesF1–F5 PASS/FAIL with exact correctionsNo approval while unresolved flow/order failures remain.
