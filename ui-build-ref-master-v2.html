Fibonacci color mapping

Use Fibonacci proportion for color mass, not as permission to add six unrelated accents. The convergence lab can generate many HEX samples; UI semantics should keep one seed accent with fixed meaning, then vary how much of that accent is present.

Interface scale
RoleSeed presenceUse
8 · background8%ambient tint / glow
5 · static surface13%panel tint / quiet boundary
3 · proof / route21%evidence rail / path cue
2 · decision34%CTA / deliberate action
1 · interaction55%hover / selection / focus-support
1 · target89%temporary handoff highlight
Convergence vs. semantics

Direct convergence: quarter-turn samples may change hue and saturation. Use them for visualizations, generated art, charts, and color-card exports.

Interface semantics: lock one seed hue and vary its presence against neutral surfaces. Large areas stay quiet; small states carry more color.

Prompt relation: decision token opens the prompt → prompt stays neutral → interaction token marks choices → target token briefly identifies the destination box.

Guardrail

Mathematical relationship does not prove accessibility. Validate actual foreground/background contrast, visible focus, disabled states, and a non-color cue for every important state. This section extends the existing rule: one accent, one documented meaning.

Build order

Sequence is real here: each step depends on the one before it.

Steps
  1. Inspect the current UI, stack and content. Pick the application type in routes.
  2. Write one sentence naming the visual direction in concrete terms.
  3. Define tokens: surfaces, ink, muted, line, one accent with one meaning. Start from techniques or a style's palette.
  4. Assign type by job; choose one geometry language.
  5. Specify empty, loading, selected, disabled, warning, error, success and long-content states.
  6. Check wide and narrow layouts, keyboard focus and reduced motion.
  7. Pass the gate, then hand off with stack-specific notes.
Validation gate full text
  • V1 Identity: describable without "modern", "clean" or "AI"
  • V2 Hierarchy: work, controls, metadata and status are distinct
  • V3 Consistency: repeated tokens mean the same thing
  • V4 Interaction: hover, focus, press, disabled, reduced-motion are deliberate
  • V5 Resilience: holds at narrow widths and with long content

A failed check means fix the current design before adding anything new.
